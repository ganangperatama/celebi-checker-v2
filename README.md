# CELEBI Checker v2

Starter project PHP Native + MySQL PDO untuk sistem pencatatan dan rekapitulasi data bagasi.

## Instalasi XAMPP
1. Salin folder `celebi_checker_v2` ke `C:/xampp/htdocs/`.
2. Jalankan Apache dan MySQL.
3. Buka phpMyAdmin, lalu import `database/database.sql`.
4. Buka `http://localhost/celebi_checker_v2/public/login.php`.
5. Login demo: `checker` / `password`.

## Catatan
Versi ini adalah fondasi awal. Modul CRUD penerbangan, data bagasi, laporan, dan scan akan ditambahkan bertahap.
